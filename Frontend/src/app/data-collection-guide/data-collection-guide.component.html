📊 X/Twitter Crawl Data Guide

Understand how to collect and prepare X/Twitter data for sentiment analysis.

🔎 Method 1: Playwright Browser Crawler

Recommended

Collect X/Twitter content directly from the browser using Playwright.

  1. Open the crawler in the app.
  2. Enter one or more keywords to search on X/Twitter.
  3. Start the crawl and wait for the collected tweets to appear.
✅ No API keys required ✅ Works with X/Twitter web pages ✅ Ideal for quick dataset creation

🗂️ Method 2: Upload Existing Crawl Data

Easy

Upload previously scraped X/Twitter raw data from JSON, CSV, or TSV files.

✅ Rapid upload ✅ Supports multiple formats ✅ Use data from other scraping tools

📚 Method 3: Public Dataset Sources

Medium

Use trusted public datasets for sentiment training and evaluation.

Kaggle Datasets:

  • Sentiment140
  • X Sentiment Analysis
  • Indonesian Sentiment Dataset
✅ Immediate access ✅ Large datasets ✅ Good for model validation

🛠️ Method 4: Browser Export Tools

Advanced

Use browser extensions and scraping tools responsibly.

Browser Extensions:

  • Tweet Harvester: Export content from a browser session.
  • Web Scraper: Capture page content to CSV/JSON.

Python Libraries:

  • snscrape: pip install snscrape
  • selenium: Browser automation for page capture
  • playwright: Advanced browser scraping and control
⚠️ Check X/Twitter terms and use ethically ⚠️ Respect rate limits and scraping policies

📋 Supported Data Formats

Crawl JSON Format (Recommended)

[
  {
    "id": "1234567890123456789",
    "text": "Ketahui informasi pembagian #PPKM di wilayah Jabar",
    "created_at": "2022-03-31T14:32:04.000Z",
    "author_id": "987654321"
  },
  {
    "id": "9876543210987654321",
    "text": "Senang sekali bisa berkunjung ke Bandung!",
    "created_at": "2022-03-31T15:45:30.000Z",
    "author_id": "123456789"
  }
]

CSV Format

timestamp,username,message
"2022-03-31 14:32:04+00:00","pikobar_jabar","Ketahui informasi pembagian #PPKM"
"2022-03-31 15:45:30+00:00","user123","Senang sekali bisa berkunjung ke Bandung!"

TSV Format (Tab-separated)

Mon Dec 04 14:38:54 +0000 2023	Senang sekali hari ini!	user123	https://x.com/user123/status/123
Tue Dec 05 09:15:22 +0000 2023	Hujan deras di Jakarta	jakarta_info	https://x.com/jakarta_info/status/456

💡 Quick Tips for Better Results

📊

Data Quality

500+ records give better sentiment accuracy than a small sample.

🎯

Keyword Strategy

Use specific Indonesian keywords like "covid indonesia", "vaksin", "lockdown".

📅

Time Range

Collect data from different dates for balanced sentiment coverage.

🔄

Mixed Sentiment

Include positive, negative, and neutral records for better training.
