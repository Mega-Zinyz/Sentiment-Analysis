📚 InSet Lexicon — Auto-Labeling & Analisis

Setiap tweet di-score berdasarkan kamus InSet (Indonesia Sentiment Lexicon). Skor > neutralMax → Positive, skor < neutralMin → Negative, antara keduanya → Neutral. Label ini menjadi training data untuk TF-IDF + ComplementNB.

Catatan: Negasi ("tidak bagus") tidak ditangani karena "tidak" adalah stopword — catat sebagai keterbatasan dalam skripsi.
← Neutral →

Default: −0.5 / +0.5. Setelah melihat distribusi, ubah dan klik "Terapkan Threshold Baru" tanpa hitung ulang skor dari kamus.
